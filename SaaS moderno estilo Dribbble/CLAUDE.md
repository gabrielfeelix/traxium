# Traxium — regras persistentes do projeto

- Nunca usar travessão (—) em textos de UI. Usar dois-pontos, vírgula ou ponto final.
- Toda tela nova deve considerar: estados de loading (skeleton com shimmer), modais/fluxos das ações visíveis (nenhum botão morto quando fizer sentido prototipar), estados vazios amigáveis.
- Estética aprovada: sidebar teal escura com ativo em degradê, cards brancos radius 18-20, split bars com degradê + hachura, avatares com anel, chips pill, botão primário degradê teal→azul. Evitar fills pastéis chapados monocolor (cara de IA).
- Fontes: Hanken Grotesk (UI) + Spline Sans Mono (códigos/números).
- Paleta: #127670, #0C5862, #093D44, #0E78B5; semânticas verde #1a8f57, âmbar #b97514/#e8a33d, vermelho #c43d3d, amarelo regime B #e3c235.
- Idioma pt-BR, dados realistas de transporte de feed (MT/MS/GO/MG), 1920px, min-width:1560px no wrapper raiz.
